# Cut-Pad
Cut-Tab is a Stardance Hackpad designed to edit with Adobe Premiere based off **SEEED XIAO RP2040**. The firmware is made with **CircutPython**!

The Marco Pad is desinged to make editing with **Adobe Premiere** easier by having switches assigned to useful and often used shortcuts while eiditng to maintain a strong workflow!
